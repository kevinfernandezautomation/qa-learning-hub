Cadena trazable

Un cambio completo con evidencia

El ejemplo utiliza un requisito ficticio de auditoría de exportaciones para MedReview Trainer.

1

Requirement

SWR-006: cada exportación de reporte debe registrar usuario, recordId, timestamp UTC, softwareVersion y resultado.

Evidencia: requirement + risk link.
2

C#/.NET implementation

public async Task<ExportResult> ExportAsync(string recordId, UserContext user) {
  var result = await _report.ExportAsync(recordId);
  await _audit.WriteAsync(new AuditEvent {
    Action = "REPORT_EXPORT",
    RecordId = recordId,
    UserId = user.Id,
    SoftwareVersion = _build.Version,
    OccurredAtUtc = _clock.UtcNow,
    Result = result.Status
  });
  return result;
}
3

SQL Server

CREATE TABLE dbo.AuditEvent(
  AuditEventId BIGINT IDENTITY PRIMARY KEY,
  Action NVARCHAR(50) NOT NULL,
  RecordId NVARCHAR(50) NOT NULL,
  UserId NVARCHAR(100) NOT NULL,
  SoftwareVersion NVARCHAR(30) NOT NULL,
  OccurredAtUtc DATETIME2 NOT NULL,
  Result NVARCHAR(30) NOT NULL
);
4

Test

Ejecute exportación con usuario autorizado. Valide HTTP/UI, archivo generado y fila en AuditEvent. Compare recordId, usuario, timestamp y versión.

Artefacto: TC-AUD-003.
5

Defect

DEF-21: el archivo se genera, pero no existe evento de auditoría. Severidad alta para el ejercicio por pérdida de trazabilidad.

Evidencia: pasos, build, query SQL y captura/log.
6

Correction

Agregar _audit.WriteAsync(...), manejar fallo de persistencia y revisar que la exportación no declare éxito si la evidencia requerida no queda registrada.

7

Retest

Repita TC-AUD-003 sobre el build corregido y ejecute regresión de exportación + audit log. Adjunte query y resultado.

Resultado: PASS solo si la evidencia coincide con el requirement.
