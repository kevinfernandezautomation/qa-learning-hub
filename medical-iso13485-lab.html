Laboratorio de sistema de calidad

Domine conceptos de ISO 13485 con un QMS ficticio

VitalTrack Medical diseña una aplicación médica ficticia y necesita demostrar que sus procesos de calidad son controlados y generan evidencia consistente.

← Volver a Medical QA LabIr a laboratorio IEC 62304 →Ver todos los laboratorios
Alcance: ISO 13485 establece requisitos para un sistema de gestión de calidad específico de medical devices. Este laboratorio usa un escenario educativo y conceptos públicos; no constituye auditoría ni certificación.
1

Defina el QMS y sus procesos

Mapee diseño, desarrollo software, compras, soporte, CAPA y control documental.

Entregable: mapa de procesos + responsabilidades.
2

Controle documentos y registros

Una persona intenta usar una plantilla de test protocol obsoleta.

  1. Defina dueño y versión.
  2. Controle aprobación y cambios.
  3. Retire versiones obsoletas del uso.
  4. Conserve registros como evidencia.
Entregable: document control log.
3

Responsabilidad y competencia

Un tester nuevo ejecutará V&V.

  1. Defina competencia requerida.
  2. Documente capacitación.
  3. Verifique autorización para la actividad.
  4. Conserve registro.
Entregable: competency/training record.
4

Controle diseño y desarrollo

La versión 2.0 agrega un nuevo workflow.

  1. Defina inputs.
  2. Genere outputs verificables.
  3. Realice reviews.
  4. Preserve verificación/validación y cambios.
Entregable: design history package ficticio.
5

Controle proveedores

Una librería externa procesa imágenes.

  1. Defina criterio de selección.
  2. Evalúe riesgo y desempeño.
  3. Documente requisitos de compra/servicio.
  4. Revise cambios del proveedor.
Entregable: supplier evaluation record.
6

No conformidad y CAPA

Tres releases repiten el mismo defecto de auditoría.

  1. Contenga el problema.
  2. Analice causa raíz.
  3. Defina corrective action.
  4. Verifique efectividad con datos posteriores.
Entregable: CAPA record + effectiveness check.
7

Control de cambios

Se propone cambiar una regla crítica.

  1. Documente solicitud.
  2. Analice impacto regulatorio/técnico.
  3. Apruebe antes de implementar.
  4. Verifique y actualice documentos.
Entregable: change control package.
8

Auditoría interna y mejora

Prepare evidencia para demostrar que el proceso funciona de manera consistente.

  1. Muestree registros.
  2. Compare práctica vs proceso definido.
  3. Registre no conformidades.
  4. Dé seguimiento a acciones.
Entregable: internal audit report + actions.
Referencia pública: ISO describe ISO 13485 como un marco para demostrar procesos de calidad consistentes en diseño, desarrollo, producción y entrega de medical devices, con fuerte relación con requisitos regulatorios y gestión de riesgos.
