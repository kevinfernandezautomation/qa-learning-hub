Curso práctico · Financial Quality Engineering

QA para Banca Digital & FinTech

Curso práctico para diseñar calidad de extremo a extremo en una banca ficticia. Use exclusivamente demos, mocks, sandboxes y datos sintéticos; no ejecute carga, seguridad ni transacciones sobre sistemas bancarios reales sin autorización formal.

← Volver al pathComenzar curso
Módulo

1. Dominio y riesgo financiero

Modele cuentas, movimientos, transferencias, pagos, tarjetas, préstamos, estados, límites, reversos, duplicados y trazabilidad. Priorice por impacto y probabilidad.

Práctica: Mapa de riesgos de una banca ficticia.

Módulo

2. Web y Mobile QA

Diseñe casos funcionales, exploratorios, accesibilidad, responsive, compatibilidad y resiliencia. Automatice flujos seguros con Playwright/Appium sobre demos.

Práctica: Suite smoke Web/Mobile en aplicación de práctica.

Módulo

3. API y contratos

Pruebe REST, autenticación simulada, códigos HTTP, esquemas, errores, idempotencia y correlación UI-backend. Use Postman/Newman o código.

Práctica: Colección API con positivos, negativos y contrato.

Módulo

4. Datos y reconciliación

Use SQL sobre datos sintéticos para verificar integridad, duplicados, saldos, movimientos y conciliación entre sistemas.

Práctica: Consultas de reconciliación en base de práctica.

Módulo

5. Automatización mantenible

Aplique Page/Screen Objects, fixtures, datos sintéticos, mocks, tags, paralelización, evidencias y reportes.

Práctica: Mini framework con UI + API + datos.

Módulo

6. Performance y resiliencia

Modele baseline, carga, estrés, spike y capacidad solo en ambientes autorizados. Analice throughput, response time, P90/P95/P99 y error rate.

Práctica: JMeter/k6 contra endpoint demo o mock.

Módulo

7. Observabilidad y diagnóstico

Correlacione síntomas del cliente con métricas de aplicación, infraestructura y datos; practique Grafana/Prometheus conceptualmente o en laboratorio local.

Práctica: Informe de cuello de botella simulado.

Módulo

8. Seguridad y privacidad desde QA

Valide autorización, manejo seguro de sesión, datos sensibles sintéticos, logging y controles básicos sin realizar pentesting no autorizado.

Práctica: Checklist de seguridad QA y privacidad.

Módulo

9. CI/CD y release readiness

Automatice smoke/regresión, evidencias y quality gates. Defina criterios Go/No-Go basados en riesgo y defectos abiertos.

Práctica: Pipeline educativo y Release Readiness Report.

Módulo

10. IA aplicada a QA financiero

Use IA para proponer casos, revisar scripts, agrupar defectos y resumir resultados; no comparta credenciales, PII, datos bancarios ni arquitectura confidencial.

Práctica: Revisión humana de un set de casos generado con IA.

Módulo

11. Métricas de calidad

Mida cobertura, defect leakage, pass rate, duración de regresión, estabilidad de automatización, tiempos de respuesta y tendencias.

Práctica: Dashboard simple con interpretación y acciones.

Módulo

12. Capstone FinTech

Integre estrategia, riesgo, Web/Mobile/API, SQL, performance, CI/CD, observabilidad y reporte ejecutivo para una banca totalmente ficticia.

Práctica: Test Strategy + suites + evidencia + decisión de release.
