RECOMENDACIONES GENERALES:

- No muestre datos reales, credenciales o información sensible.
- Cambie de visual cada 8–15 segundos.
- Termine con una microtarea.

=== MÓDULO 1: HTTP y contratos ===

VIDEO 1: Concepto esencial — HTTP y contratos
Duración objetivo: 1:30–1:55

GUION:
Hola. En este microvideo de API Quality Engineering veremos HTTP y contratos. El objetivo es entender qué significa este tema y por qué importa en stack qa. Primero identifique qué resultado queremos proteger: funcionalidad, confiabilidad, seguridad, evidencia, tiempo o experiencia de usuario. Después conecte HTTP y contratos con un requisito o riesgo concreto. Finalmente pregunte qué evidencia permitiría afirmar que el comportamiento es correcto. No memorice una herramienta sin contexto: piense en concepto, riesgo, acción de QA y evidencia. Como microtarea, complete la frase: ‘Aplicaría HTTP y contratos cuando…’ y agregue qué resultado esperaría observar.

IMÁGENES / VISUALES RECOMENDADOS:
- Diagrama simple con ‘HTTP y contratos’ al centro y cuatro ramas: requisito, riesgo, prueba y evidencia.
- Checklist limpia con 3–4 puntos.
- Antes/después: decisión sin evidencia vs decisión respaldada por evidencia.

EDICIÓN:
- Destaque máximo tres palabras clave por escena.
- Evite párrafos largos en pantalla.
- Cierre con la microtarea escrita.

VIDEO 2: Aplicación QA — HTTP y contratos
Duración objetivo: 1:30–1:55

GUION:
