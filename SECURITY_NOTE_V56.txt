No existe una forma fiable de impedir que una página HTML/CSS/JS entregada al navegador sea inspeccionada. Deshabilitar F12, clic derecho o DevTools solo crea una barrera superficial y perjudica accesibilidad. Para proteger preguntas, usuarios y pagos en producción: servir bancos de preguntas desde backend autenticado, entregar solo las preguntas del intento, aplicar autorización server-side, rate limiting, CSP/headers HTTP, no exponer secretos en JavaScript y validar pagos mediante webhooks/backend. El archivo _headers incluye una política de referencia para hosts que la soporten; GitHub Pages puede requerir un proxy/CDN para aplicar headers personalizados.
