Proyecto integrador

Capstone: calidad end-to-end

Construya una aplicación/API pequeña y demuestre el ciclo completo: requisitos y criterios ISTQB, trabajo Scrum/Jira/Azure DevOps, datos T-SQL, pruebas API Postman/SoapUI, UI Selenium o Cypress, unitarias con NUnit/xUnit/JUnit según stack, BDD con Cucumber, rendimiento JMeter y análisis SonarQube. Registre defectos y evidencias en MantisBT o Jira y gestione casos en TestLink o Azure Test Plans.

Evidencia mínima: repositorio Git, README, estrategia de pruebas, casos, scripts, datos, defectos, resultados, métricas, reporte de rendimiento y conclusiones.
