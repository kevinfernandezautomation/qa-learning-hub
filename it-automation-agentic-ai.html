Learning Path · Automation Engineering

Automatización de TI & Agentes de IA

Ruta práctica para transformar necesidades de TI en automatizaciones y soluciones con IA reutilizables, probables, seguras y medibles. Integra desarrollo, APIs, RPA, infraestructura, agentes, DevOps, cloud y Quality Engineering.

← AcademiaCurso

Competencias

1. Desarrollo para automatización

Python como lenguaje principal y fundamentos aplicados de JavaScript y PowerShell. Estructuras, módulos, manejo de errores, configuración, logging, testing y diseño reutilizable.

2. Integraciones empresariales

REST, servicios web, webhooks/eventos, mensajería, SQL y NoSQL. Diseñe contratos, autenticación, timeouts, retries, idempotencia, manejo de errores y trazabilidad.

3. RPA y low-code/no-code

Cuándo usar RPA frente a API o código. Practique flujos cloud/desktop, conectores, disparadores, acciones, excepciones y gobierno con conceptos de Power Automate y Automation Anywhere.

4. Automatización de infraestructura

Inventarios, playbooks YAML, módulos, variables, roles, secretos e idempotencia con Ansible. Diseñe automatizaciones repetibles y verificables.

5. IA generativa y prompt engineering

LLM, contexto, instrucciones, salidas estructuradas, grounding, evaluación y patrones de prompting. Distinga generación probabilística de lógica determinista.

6. Ingeniería de agentes

Agente, tools, handoffs, guardrails, estado, orquestación, trazas y Human-in-the-Loop. Diseñe permisos mínimos y confirmación antes de acciones sensibles.

7. Quality Engineering para IA

Pruebe herramientas, contratos, prompts, datasets de evaluación, regresión, resultados no deterministas, fallos parciales, observabilidad y criterios de aceptación.

8. Git y calidad de código

Repositorios, branches, commits, pull requests, code review, estándares, linters, pruebas, análisis de dependencias y criterios para certificar una automatización.

9. CI/CD y cloud

Automatice build, test y deployment; utilice quality gates. Comprenda contenedores, serverless, servicios gestionados, eventos, secretos, configuración y observabilidad.

10. Arquitectura y escalabilidad

Separe orquestación, adaptadores, reglas y datos. Analice concurrencia, reintentos, colas, caché, resiliencia, reutilización, mantenibilidad y costo operativo.

11. Innovación y liderazgo

Descubra oportunidades, formule hipótesis, prototipe, priorice por valor/riesgo y conduzca iniciativas multidisciplinarias con Agile, Scrum y Design Thinking.

12. Impacto

Mida tiempo de ciclo, horas ahorradas, tasa de éxito, errores/retrabajo evitados, disponibilidad, adopción, costo por ejecución y experiencia del usuario antes/después.

Laboratorios sugeridos

API Automation

Servicio Python que consume una API simulada, valida respuestas, persiste resultados y aplica retry/backoff sin duplicar operaciones.

RPA empresarial

Modele un proceso repetitivo ficticio con trigger, validaciones, excepciones, aprobación y evidencia de ejecución.

Ansible

Cree un inventario y playbook de laboratorio que deje un entorno en un estado definido y compruebe idempotencia.

Agente de TI

Construya un agente en sandbox con herramientas permitidas, guardrails, trazas y aprobación humana para acciones de impacto.

Pipeline

Ejecute lint, unit tests, pruebas de integración y evaluación del agente antes de permitir un despliegue de práctica.

Capstone

Desde una necesidad ficticia, entregue arquitectura, código, pruebas, threat/risk checklist, pipeline, métricas y demostración del valor generado.

Recursos oficiales

Use documentación oficial como fuente primaria: OpenAI para construcción y orquestación de agentes; Microsoft Learn para Power Automate; Ansible para automatización de infraestructura; Automation Anywhere para RPA; y GitHub Actions para CI/CD.

Práctica segura: los laboratorios deben usar sistemas propios, sandboxes, mocks y datos sintéticos. No automatice sistemas empresariales o cuentas reales sin autorización.
