Profesional y Especialista QA — .NET y Azure DevOps

Diez módulos para competencias de bachillerato y especialización de licenciatura: pruebas, automatización de APIs, desarrollo .NET, SQL, Git y CI/CD.

Alcance: 180 horas orientativas. Perfil profesional: ejecución técnica y colaboración; perfil especialista: coordinación, estrategia, automatización avanzada y liderazgo. La vacante señala licenciatura y colegiatura con ese grado para especialista; bachillerato y colegiatura activa para profesional.

Contenido y ejercicios por módulo

1. Fundamentos de calidad y requisitos

Aprenderá: Calidad de software, SDLC/STLC, criterios de aceptación, requisitos funcionales/no funcionales, trazabilidad y análisis de riesgo.

Práctica guiada: Revise 10 historias de usuario e identifique ambigüedades.

2. Scrum y Shift-Left

Aprenderá: Scrum, refinamiento, Definition of Done, pruebas tempranas, colaboración con desarrollo y revisiones de código.

Práctica guiada: Elabore una estrategia de validación desde el refinamiento.

3. Pruebas exploratorias y regresión

Aprenderá: Charters, heurísticas, sesiones exploratorias, pruebas manuales complejas, defectos y regresión crítica.

Práctica guiada: Documente 15 casos y 3 sesiones exploratorias con evidencia.

4. C# y .NET 8+ Web API

Aprenderá: POO, SOLID básico, ASP.NET Core Web API, controladores, DI, middleware, excepciones y OpenAPI.

Práctica guiada: Construya una API ficticia de solicitudes con validación y pruebas.

5. Dapper, JWT y código seguro

Aprenderá: Acceso a datos parametrizado con Dapper, JWT, autorización, manejo de secretos y validación de entradas.

Práctica guiada: Pruebe 401/403, expiración de token y consultas parametrizadas.

6. Frontend y UX/UI

Aprenderá: HTML semántico, CSS responsive, JavaScript, formularios, accesibilidad y arquitectura modular.

Práctica guiada: Construya un formulario accesible y valide teclado, errores y responsive.

7. SQL Server y PostgreSQL

Aprenderá: Joins, índices básicos, transacciones, restricciones, integridad, consultas de validación y migraciones.

Práctica guiada: Compare resultados de API con registros de una base de práctica.

8. Automatización de APIs

Aprenderá: Pruebas funcionales, integración, contrato, regresión; xUnit/NUnit, HttpClient, Postman/Newman y mocks.

Práctica guiada: Automatice 15 escenarios de API y exporte reporte.

9. Git y Azure DevOps CI/CD

Aprenderá: Branches, pull requests, YAML pipelines, ejecución de pruebas, artefactos, quality gates y variables seguras.

Práctica guiada: Configure pipeline de práctica que compile, pruebe y publique resultados.

10. Liderazgo QA y proyecto final

Aprenderá: Estrategia de pruebas, coordinación, métricas, riesgos, comunicación, revisión de cobertura y liberación.

Práctica guiada: Lidere simulación de sprint y entregue estrategia, pipeline, matriz y reporte ejecutivo.

Proyecto final y evidencias

Trabaje con una organización ficticia y datos sintéticos. Entregue plan de pruebas, matriz de requisitos/casos, defectos reproducibles, evidencias, automatización cuando aplique y un informe de calidad con riesgos y recomendación de liberación.

Rúbrica sugerida: cobertura de requisitos (25%), calidad de casos y evidencias (25%), ejecución técnica (30%), comunicación de riesgos (20%). Meta educativa: al menos 80%.

Autoevaluación de conocimientos

Seleccione una respuesta por pregunta y compruebe su comprensión. Esta evaluación es educativa y no emite certificación oficial.

1. ¿Qué expresa Shift-Left?
2. ¿Qué devuelve una API cuando falta autenticación válida normalmente?
3. ¿Qué herramienta permite configurar pipelines de CI/CD en la vacante?
4. ¿Qué práctica ayuda a prevenir inyección SQL?

Nota: completar esta formación no sustituye título universitario, colegiatura, experiencia ni certificaciones oficiales. Utilice entornos de laboratorio autorizados.
