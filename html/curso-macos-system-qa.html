Curso especializado

macOS & System QA Engineer

Planifique pruebas de aplicaciones desktop y componentes del sistema macOS, documente fallos y valide compatibilidad sin desactivar controles de seguridad.

12–16 h · Intermedio–Avanzado · 15 módulos

Contenido del curso

  1. Fundamentos de QA para aplicaciones desktop y software de sistema en macOS
  2. Compatibilidad entre versiones de macOS, Apple silicon/arquitecturas y escenarios de actualización
  3. Procesos, servicios, launch behavior, file systems e integración de bajo nivel
  4. IPC y comunicación entre procesos: conceptos, riesgos y diseño de pruebas
  5. Logs, Console, Activity Monitor, crash reports y estrategia de diagnóstico
  6. System Extensions: propósito, instalación, actualización, permisos y escenarios de compatibilidad
  7. Endpoint Security: eventos, autorización/notificación y estrategia de validación
  8. Network Extension y productos VPN/seguridad: escenarios funcionales y de compatibilidad
  9. Sandboxing, permisos, privacidad y controles del sistema: diseño de casos sin desactivar protecciones
  10. Exploratory testing: edge cases, race conditions, regresión y reproducción de fallos intermitentes
  11. Compatibilidad con aplicaciones y servicios de terceros; matriz de versiones y ambientes
  12. Triage y RCA: evidencia, aislamiento, severidad, reproducibilidad y comunicación con ingeniería
  13. Candidatos a automatización y colaboración QA–SDET; regresión sostenible
  14. Release readiness: smoke, regresión, compatibilidad y reporte de riesgo
  15. Capstone: plan de QA y triage para un producto macOS de seguridad ficticio

Actividad final

Elabore una matriz de compatibilidad, un plan de regresión y un informe de triage para un producto ficticio de seguridad en macOS. Incluya evidencia, riesgo y criterios de salida.

Referencias

Apple System Extensions · Apple Endpoint Security
