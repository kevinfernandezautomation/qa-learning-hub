Áreas principales de aprendizaje

Los siguientes temas reúnen las competencias más relevantes. Cada área conserva sus prácticas y herramientas especializadas.

1. Planificación y riesgo

Requisitos, criterios de aceptación, cobertura y trazabilidad.

2. Pruebas web

Interfaz, compatibilidad, accesibilidad y análisis con herramientas del navegador.

3. Pruebas móviles

Android, iOS, permisos, conectividad, orientación e interrupciones.

4. Servicios API

REST, GraphQL, contratos, esquemas, autenticación y pruebas negativas.

5. Microservicios y datos

Resiliencia, idempotencia, persistencia y consistencia.

6. Appium y BrowserStack

Automatización móvil, dispositivos reales, evidencias y paralelismo.

7. Cloud y CI/CD

Ejecución continua, entornos de nube, métricas y criterios de liberación.
