QA actual · herramientas demandadas en Costa Rica

Ruta de actualización para practicar competencias que aparecen en vacantes recientes de QA manual, automatización, mobile, SDET y liderazgo de calidad.

Web

Cypress + Playwright

Automatización de navegador, autenticación, sesiones, regresión, integración y exploración. Practique JavaScript/TypeScript, locators estables y diseño de suites mantenibles.

Aprender más
Mobile

Appium + Android/iOS

Dispositivos reales y emuladores, permisos, red, flujos de pagos y automatización end-to-end. Añada fundamentos de Java/Kotlin/Python según el stack.

Aprender más
API

REST + GraphQL + microservicios

Contratos, autenticación, tokens, errores, datos, dependencias y pruebas de integración. Incluya contract testing cuando varios servicios evolucionan de forma independiente.

Aprender más
Accessibility

axe-core + WCAG

Automatice comprobaciones de accesibilidad y complemente con navegación por teclado, foco visible y revisión manual.

Aprender más
Performance

Lighthouse CI + JMeter/k6

Combine performance web, carga y thresholds con observabilidad para detectar regresiones de rendimiento.

Aprender más
Gestión

Jira + Xray + TestRail + Zephyr

Trace requisitos, casos, ejecuciones, defectos, evidencias y reportes. Practique administración básica de proyectos de prueba.

Aprender más
CI/CD

Jenkins + GitHub Actions + GitLab CI + Azure DevOps

Ejecute suites en pipelines, preserve artefactos, defina quality gates y reduzca feedback tardío.

Aprender más
Senior/Lead

Métricas + release readiness + riesgo

Automation coverage, defectos escapados, tendencias, duración de regresión, resiliencia, escalabilidad y decisiones go/no-go.

Aprender más
AI-assisted QE

Triage de defectos con IA

Use IA para sugerir causas o agrupar fallos, pero conserve evidencia y Human-in-the-Loop antes de confirmar conclusiones.
